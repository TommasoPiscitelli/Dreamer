# CarRacing Dreamer with a Frozen World Model

## Project Goal

The goal of this project is to study how a reinforcement learning policy can be trained by exploiting a learned model of the environment, instead of continuously interacting with the real environment.

The case study is the `CarRacing` environment, where the agent has to learn how to control a car on a two-dimensional track by choosing continuous actions:

- steering;
- acceleration;
- braking.

The project is inspired by model-based reinforcement learning algorithms, and in particular by Dreamer, where the agent is not trained directly in the real environment, but through imagined trajectories generated by a world model.

A central choice in this project is the use of a **pre-trained and frozen world model**. This means that, during policy training, the parameters of the world model are not updated. The world model is therefore used as a fixed latent simulator, while only the decision-making components of the agent are trained.

---

## Main Idea

The world model receives a latent state of the environment and an action selected by the agent, and predicts the next latent state. Starting from these imagined transitions, it is possible to build rollouts in latent space and use them to train a policy.

The conceptual pipeline is:

```text
saved real latent states
        ↓
frozen world model
        ↓
imagined rollouts
        ↓
estimated future rewards
        ↓
policy update
